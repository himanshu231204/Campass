# Campass - Product Context

## Vision

Campass is an India's AI-first travel planning and booking app for students and budget travelers. It replaces the scattered 10-app workflow with a single **Smart Trip Plan**: an AI-generated itinerary, budget, and bookable options.

**Long-term direction:** Evolve into India's **Travel Operating System (Travel OS)**.

---

## Positioning

> For Indian students and budget travelers who juggle 8-10 apps to plan a trip, Campass is an AI travel companion that plans, budgets, and books your trip in one place — unlike MakeMyTrip or Ixigo, which are booking-first with limited planning or student focus.

---

## Problem Statement

- Students stitch together 8-10 apps (train, hotel, maps, YouTube, budget calculator, cab, translator) for a single trip
- Existing platforms (MakeMyTrip, Ixigo) are booking-first, ignore student segment (dorms, budgets, safety)
- Safety is underserved for solo/student travelers
- Weak network at destinations makes online-only apps unreliable

---

## Target User

### Primary: Budget Student Traveler
- **Age:** 18-26 college students / young travelers
- **Group:** Solo or small friend groups
- **Mindset:** Budget-conscious, comfortable with apps and AI chat
- **Travel:** Weekend trips, semester breaks, backpacking within India
- **Needs:** Cheap stays (dorms), realistic budgets, safety reassurance, no research overhead

### Secondary (Phase 2+)
- Solo travelers generally
- Families

## Competitive Positioning

| Competitor | Gap Campass Exploits |
|------------|--------------------------|
| MakeMyTrip, Goibibo, EaseMyTrip | Booking-first, weak/no AI planning, no student supply |
| Ixigo | Strong on trains, weak on end-to-end planning |
| Google Maps/Search | No integrated booking or budget planning |
| Booking.com, Agoda, Airbnb | No India-specific student/dorm focus, no Indian local transport |

**Differentiation:** AI-first planning + student-specific supply (dorms/budget hotels) + safety as trust layer.

## Key Decisions Log

| Decision Area | Outcome |
|---------------|---------|
| Primary persona | Students |
| MVP hook | AI Trip Planner + Budget Planner + Train Search + Budget Hotels/Dorms |
| Train booking model | Deep-link to IRCTC/partner |
| Hotel/dorm booking model | Full in-app via aggregator API |
| AI input method | Chat + guided form (both) |
| AI output | Smart Trip Plan (itinerary + budget + bookable options + local transport) |
| Monetization (v1) | Hotel/dorm commission + Premium AI subscription |
| Platforms | Android + iOS simultaneously (React Native) |
| Languages | English + Hindi + 2-3 regional |
| Launch geography | Pan-India (flagged as risk) |
| Offline Mode scope | Downloadable maps for saved destinations |
| Safety Hub scope (v1) | SOS + Emergency Contacts + Live Location Sharing |
| Team | Solo founder, bootstrapped |
| Timeline | Not fixed — quality over speed |
| Tech stack | React Native, Supabase/Firebase, AI-assisted dev tools |
| North Star metric | Smart Trip Plans generated + WAU/MAU |
| App name | Campass |
