# Campass - Roadmap

## Overview

Campass follows a phased approach prioritizing core value delivery first, with progressive enhancement based on user feedback and business validation.

---

## Phase 1: MVP (Current)

**Goal:** Validate core value proposition — AI planning + booking + safety

### Features

| Feature | Description | Status |
|---------|-------------|--------|
| **Smart Trip Plan (AI)** | AI-generated itinerary + budget breakdown + bookable options + local transport | 🔲 Planning |
| **Train Search + Deep-link** | Search trains/availability, deep-link to IRCTC for booking | 🔲 Planning |
| **Hotel & Dormitory Booking** | Full in-app booking via aggregator API (dorms = key differentiator) | 🔲 Planning |
| **AI Budget Planner** | Full trip cost estimation (train + hotel + food + transport + misc) | 🔲 Planning |
| **Maps & Local Transport** | Destination maps + suggested transport (auto, metro, bus) | 🔲 Planning |
| **Offline Mode (Maps)** | Downloadable offline maps for saved/booked destinations | 🔲 Planning |
| **Safety Hub (Core)** | SOS button, Emergency Contacts, Live Location Sharing | 🔲 Planning |
| **Multi-language** | English, Hindi, + 2-3 regional (Tamil, Telugu, Bengali) | 🔲 Planning |
| **Premium Subscription** | ₹199-499/month — unlimited plans, enhanced features | 🔲 Planning |
| **Authentication** | Login, signup, forgot password, OTP verification | ✅ Complete |

### Key Milestones
1. AI Trip Planner core functional
2. Hotel/Dorm booking integration live
3. Safety Hub (SOS + contacts + location) operational
4. 5 languages supported
5. Premium subscription tier live

## Risks & Mitigations

| Risk | Severity | Mitigation |
|------|----------|------------|
| **Scope vs. team size** | 🔴 Critical | Sequence technical rollout, soft-launch languages iteratively |
| **Pan-India supply dilution** | 🔴 High | Concentrate BD on student hubs (Manali, Rishikesh, Goa, Jaipur) |
| **Heavy API dependency** | 🟠 Medium | Modular backend, abstraction layer per provider |
| **No network effect vs incumbents** | 🔴 High | Differentiate via AI + safety + student pricing |
| **Customer support cost** | 🔴 High | Automated support workflows via partner APIs |
| **Thin booking margins** | 🟠 Medium | Premium subscription as second revenue leg |
| **High CAC** | 🔴 Very High | Organic growth via AI utility, referrals, content |
| **Data privacy / safety liability** | 🟠 Medium | Legal/compliance review of consent flows before launch |
| **Scope creep** | 🟠 Medium | Milestone-based checkpoints tied to feature list |
